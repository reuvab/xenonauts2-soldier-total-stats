# Changelog

## 1.0.0 — 2026-11-12

First public release.

- TOT column (Health + Time Units + Accuracy + Strength + Reflexes + Bravery) on the
  Soldiers > Manage and Recruit screens and in the dropship soldier picker.
- Click the header to sort by total; click again to reverse.
- Totals coloured red to green relative to the soldiers on the same screen.
- Stat columns are narrowed slightly so the extra column fits and every column stays aligned.
- Declared incompatible with Soldier Total Column, which covers the same screens.
